# The banner's fonts

Two typefaces, the ones nmcclure.com is set in, as Google Fonts serves them
(Latin subset, WOFF2):

- `manrope.woff2`: Manrope, variable weight. Copyright 2018 The Manrope
  Project Authors (https://github.com/sharanda/manrope).
- `dmmono-300.woff2`: DM Mono Light. Copyright 2020 The DM Mono Project
  Authors (https://github.com/googlefonts/dm-mono).

Both are licensed under the SIL Open Font License, Version 1.1
(https://openfontlicense.org), which each file also carries in its own
metadata. They are used only to draw the banner; no plugin ships them.
