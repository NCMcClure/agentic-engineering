# Changelog

- **1.0.0**: The twelve plugins became this one. Each is now an area (agent-works, agentic-teamwork, but-first-planning, code-diet, codebase-optimizer, docs-parity, perceptual-loop, picture-this, plugin-workbench, system-map, workflow-studio, write-like-me), and the context lens left plugin-workbench to be a thirteenth, context-doctor. What was a skill is a route: a `ROUTE.md` its area reads by path, never listed, so the skill listing holds fourteen names where it held about eighty. An agent calls an area with the route as the first word of its arguments, `/agentcraft:<area> <route>`; a person types `/agentcraft:start-here`, the only entry in the slash menu, or asks for the work in words. A skill only a person could start is a route its area marks so, and an agent takes it only when the person asked. The twelve old names stay as stubs that depend on this plugin, so an update of one brings it in; install `agentcraft` by name as well, so it stays when the stubs go. An area's own `CHANGELOG.md` is its history up to the move and takes no new line.
- **0.1.0**: The `start-here` skill, on its own. Typed with no argument it asks which areas a person wants in up to four grouped questions, explains each one chosen, asks how they want to use it, and hands off to the skill that does the work. Given a task, or with nobody to ask, it asks nothing and names the area and skill that fit. The areas are the twelve agentic-engineering plugins, and a hand-off goes to one of their skills by its address; a skill only a person can start is named for them to type.
