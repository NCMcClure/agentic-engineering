# Changelog

- **0.2.0**: A 3D tier. Two new archetypes, `iso-flow-3d` and `layer-stack-3d`, draw the same model on React Three Fiber: clay, matte black, frosted glass and the accent, soft shadows, flat labels over the canvas, driven by the same clock. The kit gains `three/`, copied into a repo only with `kit install --three` or by landing a 3D draft; the 2D tier still depends on React alone. The studio carries three.js, so 3D drafts and stills add nothing to a repo, and stills are drawn in software so they are the same on every machine. The `visualize` skill asks before a 3D figure adds packages to a site.
- **0.1.0**: First release. Replaces `animated-storytelling`, which explained ideas as decks; this one draws systems. Two skills: `visualize` (model the system, draft three variations, refine one, deliver a React component for MDX) and `export-stills` (light and dark PNGs for a README). Ships a copy-in kit, a studio that renders drafts and stills, and the `pt` CLI. The contrast checker carries over as `scripts/contrast-check.mjs`.
